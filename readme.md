md语法备忘

| 功能 | 语法 |
|---|---|
| 标题 | `# 标题` |
| 粗体 | `文字` |
| 斜体 | `*文字*` |
| 删除线 | `~~文字~~` |
| 行内代码 | `` `代码` `` |
| 代码块 | ` ```语言 代码 ``` ` |
| 无序列表 | `- 项目` |
| 有序列表 | `1. 项目` |
| 引用 | `> 文字` |
| 链接 | `[文字](URL)` |
| 图片 | `![描述](URL)` |
| 表格 | `\| 列1 \| 列2 \|` |
| 分割线 | `---` |
